Project Overview:
In Server B, the web application/webpage is deployed using an Apache Web Server.
If we want to make changes to the webpage, instead of manually making changes on the server, we can use Jenkins.
Jenkins will bring the updated code from GitHub and deploy it to Server B using the Apache Web Server.

GitHub → Jenkins (server A)→ Server B → Apache Web Server→ Webpage
